- 2 × ActorSystem 进程（单桌面 WSL2，47GB 内存）：shard0 = 5051 actor，shard1 = 5050 actor
- 交叉配对分片：shard0 的 5000 worker → 报数给 shard1 的 mid_1..50；反之亦然 —— **9,999 封报数信 100% 跨进程 TCP**
- LLM 代理全局闸门 = 1（模型侧严格串行）；codex 进程闸门 = 4/分片；codex 同时存活 ≤ 8

2. 04:58 上游 API 挂起 4 分钟，代理 300s 超时自愈（加固项：上游看门狗收紧到 60s）
