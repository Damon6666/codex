 消息格式速查 (InterAgentWire, peer.rs:8):
   from_shop/to_shop : 店名(即actor路径 shops/<name>)
   from_thread       : 发信会话的ThreadId
   body              : 信件正文(给审查员必须是代码原文)
   trigger_turn      : true=收信方必须开新turn(followup语义)
                       false=只投递入上下文,等下次自然turn(send_message禁止用于回信)
   encrypted         : true=body是API侧加密参数(需原样回传)
   shutdown          : true=请对端退网, 不开turn
 店规红线 (PULSING.md):
   回信只能用followup_task / 审查信必须贴代码原文 / 最多打回3轮 / 最终中文汇总
